# Caprock — Premium Fintech UI

A modern, responsive fintech application built with React, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- **Login & Sign Up** — Split-screen auth with glassmorphism, animated backgrounds, and social login placeholders
- **Onboarding** — Multi-step flow with progress tracking and interactive option cards
- **Dashboard** — Portfolio overview, balance card, performance chart, asset allocation, and transaction history
- **Design** — Black, white, and `#003478` palette with Syne + DM Sans typography
- **Motion** — Page transitions, hover effects, chart animations, and micro-interactions throughout

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4
- Framer Motion
- React Router v7
- Lucide React icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Routes

| Path | Page |
|------|------|
| `/login` | Sign in |
| `/signup` | Create account |
| `/onboarding` | New user setup |
| `/dashboard` | Main dashboard |

## Scripts

- `npm run dev` — Start dev server
- `npm run build` — Production build
- `npm run preview` — Preview production build
